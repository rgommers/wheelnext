# Options Analyses

Companion artefacts to the [Wheel Variants requirements](../requirements.md) and the PEP series. Each options analysis weighs alternatives for a single load-bearing design decision against the requirements, recommends one, and records dissent. See the [overview](../index.md#options-analyses) for the role these play alongside the PEPs.
